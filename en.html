ELUPON VUNOS

The project’s own operating system: light, fast and minimal, built on Debian 8. It ships with basic software for everyday work. Made for enthusiasts, developers and anyone who wants to try an experimental environment.

Important: the system runs only in Live CD / Live USB mode, with no installation to a hard drive. The downloaded .zip contains an .iso image. Write it to a USB drive using Rufus only.

How to install an APK

  1. Tap “Download APK” and wait for the file to finish downloading.
  2. Open the file on your smartphone using any file manager.
  3. If the system blocks the installation, open the settings that appear and allow “Install from unknown sources” for your browser or file manager.
  4. Go back to the file, tap “Install” and wait for it to finish. All ELUPON builds are checked and safe.
